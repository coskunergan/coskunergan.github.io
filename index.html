About

What I work on, what is on the bench, and what you can run right now from this page.

I build things that live inside the wire: firmware, telemetry channels, and the small amount of web tooling needed to debug them from a browser. The work sits between embedded C/C++ on microcontrollers and the protocol side of the devices that talk to them — mobile modems, GNSS, over‑the‑air updates, and the AT command surface underneath all of it.

Most of it runs on an ESP32‑S3 on a bench with a soldered‑on cellular module. A browser page is the fastest thing to reach for, so the debugging tools are web pages: an AT‑command console that reaches the board through a Firebase channel, a hash‑puzzle lab, and the oscilloscope above — drawn pixel by pixel in canvas 2D, no libraries, no build step.

AT Command Console ▍ open

Send a raw AT+CSQ, AT+CEREG? or AT+QENG="servingcell" and watch the board answer. The console tries the device's local API first, then falls back to a Firebase RTDB channel, and prints every TX / RX line with millisecond timestamps.

Proof‑of‑Work Lab

H(message, nonce) with MD5, run over an incrementing nonce until the digest starts with N leading zeros. The message is editable, the difficulty is a dial, and the counter runs in front of you — the classic hashcash preimage search in a few dozen lines.
